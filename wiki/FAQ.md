# Frequently asked questions

**Does it change my original game?** No. A new file is written where you say.

**Do I need to install Java?** Not with a release archive, it has its own. From source you need JDK 25.

**Why does it say my game is not an unmodified retail dump?** The file differs from the known good dump in some part. The message lists which parts and which options may not work. Randomization often still works; extras that patch code need exact bytes and may refuse.

**Why can't it fill my PC boxes with eggs directly?** A game file has no save in it. See [Egg box](Egg-box).

**Will my shiny Pokemon stay shiny in other games?** No, see [Real shiny chance](Real-shiny-chance).

**Is it safe to open the web interface?** It listens only on your own computer and needs a token that changes every run. See [The web interface](The-web-interface).

**A 3DS game will not open.** It must be decrypted, and the program needs about 6 GB of memory: use the launcher.

**Where do I report problems?** On the Issues page of the repository. It is a personal project, replies may take a while.
