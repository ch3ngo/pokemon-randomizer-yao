1. HOW TO USE (recommended)

Double-click the web launcher (web-launcher.*) to open the Pokemon Randomizer YAO interface in your web browser.
It runs only on your own computer; keep its window open while you use it.
This is necessary for being able to randomize 3DS games (it needs more memory than a browser alone allows).

[LINUX_ONLY]The launcher script assumes you have bash installed at "/bin/bash".
[LINUX_ONLY]This should be the case for most Linux distributions.
[LINUX_ONLY]If your distro does not have bash at "/bin/bash", modify the launcher script,
[LINUX_ONLY]or run the Randomizer JAR manually through the console.
[LINUX_ONLY]

2. THE OLD INTERFACE (legacy, not restyled)

${launcherName} opens the original desktop interface inherited from this project's upstream (Universal Pokemon
Randomizer FVX). It still works, but its window title, About dialog and wiki links have not been updated for this
fork yet. Use the web interface above unless you have a specific reason not to.

Note: the legacy interface and this file itself live inside the "app" folder, alongside the randomizer program,
its data files and its bundled Java runtime. Most people never need to open that folder; web-launcher.* is the
only thing you should normally run, and it is one level up from "app".

DO NOT change the name of the randomizer program (PokemonRandomizerYAO.jar) as this will cause either launcher to fail.
Do not rename or move the "app" folder.
