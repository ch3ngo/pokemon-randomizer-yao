# Where static, gift and in-game trade Pokemon are found (added for YAO, 13/10/2026).
#
# No game handler reads this from the ROM: the encounter data holds only species, level and flags, and the trade
# data holds no map at all. So the places are a maintained table, one section per game family, matched against the
# ORIGINAL game's own list by species and level (never by position, so the Spanish dumps, whose lists are shorter or
# ordered differently, still match). Compiled from Serebii's per game pages and the pret decompilation projects.
#
# Lines:
#   @family <key>                      starts a section (crystal frlg emerald dp platinum hgss bw bw2 xy oras sm usum)
#   P|<TAG>|<english>|<spanish>        a place or phrase the shared place table does not have
#   S|<species>|<level or *>|<place>   a static, gift or egg Pokemon
#   T|<wanted>|<given>|<place>         an in-game trade (wanted may be * for "any Pokemon")
# Species are English names (or #<number> where a name is ambiguous). <place> is free text where {TAG} is replaced
# by the place's name in the reader's language, from the guide's own place table or a P line above. Text after " || "
# is the Spanish version of the free text (without it the same text is used, so use only {TAGS} and punctuation).
# A species listed twice at the same level is matched in order, so repeated encounters can each have a place.
